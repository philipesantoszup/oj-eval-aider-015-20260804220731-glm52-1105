The TLE (Time Limit Exceeded) in "Synthesized test 2" is caused by the `find` and `delete` operations traversing long linked lists of deleted nodes on disk. Since deleted nodes are only marked as deleted but remain in the linked list, a sequence of many inserts and deletes on the same key results in O(N) disk reads for every subsequent `find` or `delete`. Additionally, allocating a `std::vector` and sorting it for every `find` operation adds significant overhead.

To fix this:
1. **Unlink deleted nodes**: Instead of marking nodes as deleted, we will unlink them from the linked list. This keeps the list size proportional to the number of active entries.
2. **In-memory node cache**: Since the total number of entries is at most 100,000, the total size of all `ValueNode`s is at most 1.6MB. We will load all nodes into a global memory array at startup. This eliminates disk I/O for linked list traversal, making `find` and `delete` extremely fast.
3. **Static array for sorting**: We will replace the `std::vector` in `find_record` with a static global array to avoid heap allocation overhead.
